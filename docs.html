参数说明

参数名 类型 默认值 说明
form string text （保留原有） 输出格式。可选值：text / json / xml / ini
encode string — （新增） 输出格式别名，优先级高于 form，便于与其他一言服务兼容。
c string （全部分类） （新增） 分类筛选。单个：?c=a；多个用英文逗号：?c=a,b,c。不传则随机全部分类。
charset string utf-8 （新增） 响应字符集，如 ?charset=gbk。

示例 2：JSON 格式 + 指定分类
返回完整元数据。
GET ?encode=json&c=a

// Response (application/json)
{
  "hitokoto": "你不会死的，因为我会保护你。",
  "message":  "你不会死的，因为我会保护你。", // 兼容旧版
  "type":      "a",

  "from_who":  null,
  "creator":   "绫波丽",
  "length":    14
}
示例 3：多分类 + XML
从漫画、游戏、文学三个分类随机。
GET ?form=xml&c=b,c,d
示例 4：INI 格式 + 诗词 + 网易云
适合 ini 解析场景。
GET ?form=ini&c=i,j
