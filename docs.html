参数说明

参数名 类型 默认值 说明
form string text （保留原有） 输出格式。可选值：text / json / json5 / xml / ini / toml / js / sh / bat / ps1
encode string — （新增） 输出格式别名，优先级高于 form，便于与其他一言服务兼容。支持与 form 相同的全部 10 种格式。
c string （全部分类） （新增） 分类筛选。单个：?c=a；多个用英文逗号：?c=a,b,c。不传则随机全部分类。
charset string utf-8 （新增） 响应字符集，如 ?charset=gbk。

元信息说明： 除 text 格式仅返回一言内容外，其余 9 种格式都会在响应中包含 API 地址（api）、开源仓库地址（repository，含 gitee / github / codeberg）与 开源协议（license: AGPLv3，license_url）。

调用示例

示例 1：最简调用（默认 text，全分类随机）
直接返回纯文本一言。
GET 

// Response (text/plain)
樱花飘落的速度，是每秒五厘米哦。
示例 2：JSON 格式 + 指定分类
返回完整元数据。
GET ?encode=json&c=a

// Response (application/json)
{
  "hitokoto":   "你不会死的，因为我会保护你。",
  "message":    "你不会死的，因为我会保护你。", // 兼容旧版
  "type":        "a",
  "from":        "EVA",
  "from_who":    null,
  "creator":     "绫波丽",
  "length":      14,
  "api":         "https://your-domain/",
  "repository":  { "github": "https://github.com/ByUsiStudio/hitokoto-api", /* ... */ },
  "license":     "AGPLv3",
  "license_url": "https://www.gnu.org/licenses/agpl-3.0.html"
}
示例 3：多分类 + XML
从漫画、游戏、文学三个分类随机。
GET ?form=xml&c=b,c,d
示例 4：INI 格式 + 诗词 + 网易云
适合 ini 解析场景。
GET ?form=ini&c=i,j
示例 5：SH 格式（Shell 变量）
可直接 eval 用于 Shell 脚本。
GET ?encode=sh

# Response (application/x-sh)
HITOKOTO='樱花飘落的速度，是每秒五厘米哦。'
HITOKOTO_FROM='秒速五厘米'
API_URL='https://your-domain/'
LICENSE='AGPLv3'
示例 6：JS 格式（变量赋值）
前端可通过 <script src> 直接引入并读取 hitokoto 变量。
GET ?encode=js&c=a

// Response (text/javascript)
var hitokoto = {
  hitokoto: "你不会死的，因为我会保护你。",
  from:    "EVA",
  api:     "https://your-domain/",
  license: "AGPLv3"
};
