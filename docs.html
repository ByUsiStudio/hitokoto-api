参数说明

参数名 类型 默认值 说明
form string text 输出格式，可选：text / json / json5 / xml / ini / toml / js / sh / bat / ps1
encode string 无 输出格式的别名，优先级高于 form，支持与 form 相同的 10 种格式，方便兼容其他一言服务。
c string 全部分类 分类筛选。单个分类用 ?c=a，多个用英文逗号，如 ?c=a,b,c。不传就在全部分类里随机。
charset string utf-8 响应字符集，如 ?charset=gbk。

元信息说明： 除 text 只返回句子内容外，其余 9 种格式的响应都会带上 API 地址（api）、 开源仓库地址（repository，含 gitee、github、codeberg）和开源协议（license: AGPLv3、license_url）。

调用示例

示例 1：最简调用（默认 text，全分类随机）
直接返回一段纯文本。
GET 

// Response (text/plain)
樱花飘落的速度，是每秒五厘米哦。
示例 2：JSON 格式 + 指定分类
返回完整元数据，uuid、creator_uid、reviewer、commit_from 等字段都在里面。
GET ?encode=json&c=a

示例 3：多分类 + XML
从漫画、游戏、文学三个分类里随机取一条。
GET ?form=xml&c=b,c,d
示例 4：INI 格式 + 诗词 + 网易云
返回 INI 格式，可以直接交给 INI 解析器读取。
GET ?form=ini&c=i,j
示例 5：SH 格式（Shell 变量）
可以直接 eval 到 Shell 脚本里。
GET ?encode=sh

# Response (application/x-sh)
HITOKOTO='樱花飘落的速度，是每秒五厘米哦。'
HITOKOTO_FROM='秒速五厘米'
API_URL='https://your-domain/'
LICENSE='AGPLv3'
示例 6：JS 格式（变量赋值）
前端用 <script src> 引入后，就可以读取 hitokoto 变量。
GET ?encode=js&c=a

// Response (text/javascript)
var hitokoto = {
  hitokoto: "你不会死的，因为我会保护你。",
  from:    "EVA",
  api:     "https://your-domain/",
  license: "AGPLv3"
};
